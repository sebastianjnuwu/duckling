# Duckling

Idle 2D em Go + Ebiten: menu com pato animado, loja,
opções (3 idiomas, música/SFX separados) e loading com música.

## Rodar
- `go run .` (ou `air`)
- Requer Go 1.26.

## Build (`make ...`)
- `run vet build-win64 build-win32 web pack size clean`
- Saída em `tmp/`.

## Suporte
- Windows 10/11, 32/64-bit (`build-win64`).
